# OWASP-Prompt-Injection-Research
This is for transparency in the work related to the OWASP Top 10 for GenAI Prompt Injection Entry. This repo was started for the 2025 to 2026 changes.

As the [OWASP GenAI Security Project](https://genai.owasp.org/) lead for the Prompt Injection Entry for the [Top10 for GenAi](https://github.com/GenAI-Security-Project/GenAI-LLM-Top10) I wanted to provide this repo for transparency purposes as part of the dedication to this principle as a member of an open-source project. 

This reposity will include:
- A documented log of the suggestions and submissions for change for the Prompt Injection entry. The best way to make a suggestion is to submit a PR for the [GenAI Github](https://github.com/GenAI-Security-Project/GenAI-LLM-Top10) but I do make an effort to account for feedback provided in Slack Channels such as the dedicated one for [prompt injection](https://owasp.slack.com/archives/C0AT20EKUGZ) and the overall [top10 feedback](https://owasp.slack.com/archives/C098NMFETD5) channel
- Prompt Injection research and analysis
- Analysis commentary as it relates to suggestions
- Rationale for changes and rejected changes
